# Instrucciones del proyecto

Las reglas de este proyecto están en **[`CLAUDE.md`](./CLAUDE.md)**, en esta
misma carpeta.

Ese archivo se llama así por convención de una herramienta, pero **aplica a
cualquier asistente de programación** que trabaje aquí: Antigravity, Gemini,
Cursor, Copilot o Claude Code.

**Léelo completo antes de modificar nada.** Documenta las trampas del proyecto
que ya costaron tiempo real: por qué el optimizador de imágenes está
desactivado, el límite de tamaño de los archivos que se suben, y los pasos
obligatorios después de cambiar el panel de administración.
